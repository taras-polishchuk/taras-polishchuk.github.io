Infrastructure inventory

pve-x + LXC + Cloudflare Tunnel + PBS + legacy IONOS/Hetzner

🔒
This module is locked
  • Complete "How everything connects" to unlock this module.

Purpose

Know which physical/virtual asset is doing what. The current primary deployment is on **pve-x** (Dell R720, Proxmox 9.2.2, Cluster INDYN-CL) with 4 LXC containers behind a Cloudflare Tunnel; an older Coolify deployment on IONOS/Hetzner still runs 51 client projects.

Learning outcomes

  • Name pve-x and its 4 LXC containers (CT700-703) and what each hosts
  • Explain why VLAN 11 (INDYN-DEV-AI) is segmented from Corp VLAN 10
  • Trace traffic from Internet to a product through Cloudflare Tunnel + Access
  • Locate the canonical source of truth (the docs/ folder) for infrastructure facts
  • Identify active risks (INF-001..013) and the open backup gap
