A · Визначення

Що це таке

Potenzial-Scan Lite — це 5-хвилинна structured-діалогова AI-оцінка, яка допомагає німецькому Mittelstand відповісти на одне конкретне питання: «Чи має сенс AI для мого конкретного процесу — і якщо так, то де саме?»

Де живе Potenzial-Scan Lite у воронці продажів InsideDynamic

Для кого

  • target Німецький Mittelstand · 10–250 співробітників
  • scope Конкретний процес, не «AI взагалі»
  • fit Owner / decision-maker, який готовий говорити про цифри

Чому саме так

  • gap Mittelстанду бракує швидкого способу відсікти «AI не для нас» від «AI потрібен ось тут»
  • role Не продає AI — допомагає відвідувачу самому зрозуміти, чи є сенс
  • handoff Sales-ready MQL → Odoo CRM → Setter → Closer (не auto-close)
B · Маршрут

Як працює: 8 кроків відвідувача

Кожен крок = один API-маршрут. Жоден крок не вимагає реєстрації. Кожен крок має одну конкретну мету. Жоден крок не вигадує цифри.

Старт

Відвідувач відкриває landing. Без форми реєстрації.

POST /api/scan/start

Контекст компанії

Розмір, галузь, роль. Без PII.

/scan/step1

Опис болю

Який процес болить. Вільний текст або chip.

/scan/step2

Адаптивні питання

1–2 deterministic. Тільки якщо потрібно.

/scan/adaptive

Калькулятор

Поточне навантаження. Сценарії від користувача.

/scan/calculator

AI-аналіз

LLM ранжує 3 сценарії. Без вигаданих цифр.

/scan/complete

Popup-и телефону

Опційно на кроках 1, 2, перед complete. Опційний email.

/popup/* + /contact/start

Фінальний шлюз

Email + телефон обов'язково → доступ до результату.

/result/access

C · Стек

Архітектура: один стек, один deployable

Без мікросервісів. Без Python. Один TypeScript-репо. Один Postgres. Один LLM-постачальник (на Gate A-1). Один CRM (Odoo). Два ізольованих restore-домени (CT703 + CT-DL-X).

Trust boundaries · єдиний deployable

Stack freeze

  • lang TypeScript strict · одна мова · без Python
  • fw Next.js App Router · pinned at scaffold
  • db PostgreSQL 16 · Drizzle · Zod на кожному боундарі
  • test Vitest + Playwright
  • repo mvp-product/ · app/ + ledger/ packages

Інфраструктура

  • edge Cloudflare (TLS · WAF · Turnstile)
  • CT703 mvp-app (Lite MVP)
  • CT700 Coolify + Plausible + ClickHouse
  • CT-DL-X deletion-ledger (окремий restore-домен)
  • PBS щоденний backup до Hetzner Storage Box DE

E · Scope

Що в scope · Що поза scope

Чіткі межі Lite MVP. Те, чого немає тут — це не «coming soon». Це або в наступному релізі, або свідомо виключене.

В scope (Lite MVP)

  • Landing · server component · German/Ukrainian
  • 5-хв scan flow (step1 · step2 · adaptive · calc · AI)
  • Pattern-based qualification (hoch / selektiv / unzureichend / nicht_empfohlen)
  • Popup-driven phone capture (multi-stage)
  • Final gate: email + phone both verified
  • Odoo 19 Custom handoff (JSON-2 · bearer · canonical DTO)
  • GDPR deletion saga (8 кроків · idempotent)
  • Plausible analytics (categorical · 22 events)
  • CT-DL-X deletion ledger (separate restore domain)

Поза scope (свідомо)

  • Persistent user accounts · 14-day trial
  • AI voice · SIP · VAPI · TalkHub
  • Booking widget · calendar integration
  • Multi-tenant SaaS admin panel
  • RAG / knowledge product · persistent KB
  • Local sales state duplication (X-31)
  • BANT-style invented sales data (X-34)
  • SDR/AE/IT specific person assignments (X-27)
  • AI provider fallback chain (X-28)
  • Per-lead Odoo feedback ingestion (X-31)
